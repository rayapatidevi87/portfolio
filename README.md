# Portfolio Website

This project is a semantic HTML5 portfolio website built with accessibility and SEO as top priorities.

## Features
- Semantic HTML structure
- WCAG accessibility compliance
- ARIA roles and labels
- Keyboard navigable UI
- SEO optimized meta tags
- Responsive design
- Accessible contact form

## Outcome
Achieves high Lighthouse scores in Accessibility and SEO.
